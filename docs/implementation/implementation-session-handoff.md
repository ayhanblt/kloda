## Beşinci implementation dilimi — phase-bound acknowledged recovery

- `pending_upload.phase`: `prepared|uploaded|moving|moved|conflict|unknown`. Scope ve phase migrasyonu tek transaction'dadır; eski aşamasız kayıtlar `unknown` olur, ack tahmin edilmez. Row target/source/path/hash/temp/old-phase'e bağlanır; duplicate insert eski temp'i replace etmez, transition/clear CAS stale descriptor'ı reddeder. `moved` exact row'u silme + receipt insert tek cached SQLite transaction'dır; iki SQL failure noktasında rollback ve reopen/retry unit test edildi. Ayrı koşulsuz receipt setter kaldırıldı.
- Split transfer: parent collection'lar standart MKCOL ile oluşturulur (201/405;405 tek başına collection/authority proof'u değildir, sonraki PUT failure propagate edilir), PUT `If-None-Match:*`, MOVE `Overwrite:F`. Yeni file mapping için yalnız201 ack;412 conflict,204/207/diğer status veya network failure ack sayılmaz ve temp otomatik silinmez.
