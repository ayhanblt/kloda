## Locale komutu — yalnız uygulamada değişen locale doğrulaması

Repo kökünde; dosya yazmaz, iki uygulamayı birbirleriyle eşitlemez. Bir app içindeki
üç dilin yaprak anahtarları ve interpolation adları karşılaştırılır. İlgili render
testlerinin yerini tutmaz; plan keşfinde çalıştırılmadı.

```sh
python3 - <<'PY'
import json, re
from pathlib import Path
def flatten(value, prefix=''):
    if isinstance(value, dict):
        return {key: text for name, child in value.items()
                for key, text in flatten(child, f'{prefix}.{name}').items()}
    assert isinstance(value, str), prefix
    return {prefix: sorted(re.findall(r'\{\{\s*([^{}]+?)\s*\}\}', value))}
for app in ('mobile', 'desktop'):
    root = Path('apps') / app / 'src/shared/i18n/locales'
    values = [flatten(json.loads((root / f'{lang}.json').read_text())) for lang in ('tr', 'en', 'de')]
    assert values[0] == values[1] == values[2], f'{app}: key/interpolation mismatch'
    print(f'{app}: JSON + key/interpolation parity OK')
PY
```
