# Kloda — Capability/authority kabul matrisi

**36 hedefin tamamı `not-executed`.** [ADR0013](../decisions/0013-qr-based-local-lan-pairing.md) backend-independent QR LAN trust yönüdür; [ADR0012](../decisions/0012-kloda-owned-p256-device-identity.md) P-256 identity/hardware preference için korunur. Matrix/SAS active path'ten çıkarılmıştır. ADR0004 authorization/exact-DER LAN semantiği, provisional ayrı server ES256 custody korunur. [KLODA-QR-PAIR-V1 protocol bytes ve minimum native davranış](qr-pairing-v1-protocol.md) frozen; actual API/ABI/adoption/integration unverified, implementation not executed. Eski01–32 ve27a/18a/31a/31b ID'leri korunur; gerçek native/admission/operation/publication kanıtı gerekir. Ayrı QR roadmap testleri veya scoped Android signer PASS bu36 authority hedefini pass yapmaz.

Kaynak anahtarları: **AC** tarihsel32 hedefin01–32 karşılığı; **ADR** [ADR0003](../decisions/0003-secure-pairing-and-offline-authorization.md); **SD** [security design](secure-pairing-design.md); **VM** [ADR0007](../decisions/0007-matrix-verification-and-device-continuity.md) tarihsel Matrix mekanizması; **K12** [ADR0012](../decisions/0012-kloda-owned-p256-device-identity.md) P-256 identity; **Q13** [ADR0013](../decisions/0013-qr-based-local-lan-pairing.md) current QR trust; **D** [profile](capability-profile.md). Registered JWT/JWS/cnf alanları legacy source/logical referanslardır, yeni serialized schema değildir; login JWT yalnız backend session. Historical Matrix TLS/SAS yeni QR/hardware/session/remote kanıtı değildir. Kökenler [session inventory](../implementation/session-documentation-index.md) içinde korunur.

Ortak kalıcılık invariant'ı: ret/fence/recovery trusted mapping/key/scope'u attacker input'tan genişletmez; yeni admitted authority, publication veya completed üretmez. Önceden geçerli durably committed normal PC final, journal/staging/ciphertext ve mevcut key korunur. Journal authority değildir. Scope dışı dosyalarda read/write/publication yok. ## Ayrı review geçişi — tamamlandı

Önceki Matrix single-key scope'ta `AcceptancePolicyReview` orijinal01–32/ADR/SD/VM için36 unique ID ve tüm `not-executed` statülerini, `CapabilityProfileReview` RFC/source/evidence kapsamını gözden geçirdi; actionable finding bulunmadı historical sonucudur. Request-start/strict24h, expiry, deny/late-allow, iki commit sırası, preservation/reconcile ve cert/key ayrımı belge üzerinde takip edildi; ADR0012 cutover/new provider proof review sonucu değildir.

Bu ayrı yazım-sonrası review'dur;36 test pass, peer-DER admission export, JWT interoperability, filesystem atomikliği veya fiziksel/real-network güvenlik sertifikası değildir. Runtime eksikleri yukarıdaki kolonlarda açık kalır.
