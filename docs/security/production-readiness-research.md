# Kloda — Production readiness kaynak araştırması (2A)

**Current supersession — ADR0013 (kayıt: 2026-10-07):** Bu2A araştırma **eski Matrix Ed25519 single-key/software-only/same-key TLS scope'unun tarihsel source kaydıdır**; aşağıdaki kabul sınırları, matrisler, blocker/next prerequisite/2B seçenekleri ve future smoke'lar o scope'a aittir, current contract/execution planı değildir. [ADR0013](../decisions/0013-qr-based-local-lan-pairing.md) Matrix/SAS/SDK/store/homeserver/upstream/fork işlerini current initial pairing'den çıkarır; historical araştırma yalnız archival/non-actionable'dır. [ADR0012](../decisions/0012-kloda-owned-p256-device-identity.md) hardware-preferred Kloda P-256 identity/local pin için korunur. Backend registry pin yaratmaz.

Current first trust local QR LAN'dır: PC QR canonical SPKI SHA256 actual TLS'teki Kloda P-256 key ile eşit, actual mutual TLS possession + same-channel secret HMAC + exact reserved candidate PC approval + durable consume/pins/ACK. Backend/login/internet olmadan trust mümkündür; enrollment/step-up/PC scope/capability/file grant yaratmaz. [KLODA-QR-PAIR-V1](qr-pairing-v1-protocol.md) protocol bytes/HMAC/exporter/lifecycle ve minimum native davranış frozen; actual API/ABI/adoption/integration unverified, implementation not executed. [QR roadmap](../implementation/qr-pairing-implementation-roadmap.md) future implementation/test hedefidir. Full-DER capability binding ve same-TLS-key/new-DER online reissue QR SPKI hash'inden ayrıdır; remote WebRTC/DTLS/signaling/P2P/Cloudflare TURN yönü ayrı kalır.

Required key/pin/pairing/epoch continuity kaybı fresh QR trust + ayrı gerekli online file authorization ister. Provider/API/background/fallback/Linux/iOS/desktop/LAN gates açık; [production gates](production-gates.md) SM-S921B/API36 device-local hardware-backed P-256→TLS1.3 CertificateVerify **CLOSED/PASS**'ını yalnız dar alt-gate olarak ayırır. Aggregate platform veya authority closure değildir. Historical dates/counts/pins/hash/results korunur; bu cutover'da araştırma/deney rerun yok.
