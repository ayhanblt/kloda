## Yanlış çıkarım yapılmayacak varsayımlar

- 14 Android transport pass ≠ direct pass/full product complete; failed direct transfer'ın TURN cleanup'u direct payload proof değil. Wi-Fi manual continuation ve failed/blocked denemeler final başarının yanında durur.
- iOS native verification/TLS pass ≠ iOS URLSession background/certificate strategy proof; mimari retained kalır, eski inconclusive silinmez.
- QR completion/login JWT/registry ≠ file access; scope+current capability/authority+fresh mutual proof+time/deny/version/fence birlikte gerekir. Backend registry pin yaratmaz; Matrix/SAS current gate değildir.
- exp/nbf NumericDate semantics ≠ trusted clock; process restart/late allow/iat/token renewal yeni offline pencere değildir. Reachable authenticated denial unreachable network değildir.
- Aynı private key/SPKI ≠ aynı DER cert; QR canonical SPKI hash exact LAN full-DER capability hash'i değildir. Initial QR PC identity actual TLS P-256 SPKI ile eşittir; new-DER capability online reissue ister. Historical donor inspection renewal runtime proof değildir.
- Kaynak doküman/destek tablosu ≠ runtime/KMS/provider interoperability; JS/header cert ≠ TLS possession; trusted root ≠ actual leaf key pin.
- Software epoch/hardware retention ≠ install continuity/perfect rollback detector; ThisDeviceOnly ≠ guaranteed reinstall deletion; transient lock ≠ key loss. Required local continuity kaybı fresh QR trust + ayrı gerekli online authorization ister; old Matrix store current dependency değildir.
- Cloudflare TURN seçilmiş relay fallback yönüdür, deployment/credentials/background proof değil; public endpoint veya credentials pairing/pin/scope authority değildir. Optional payload encryption TLS/DTLS veya peer proof yerine geçmez; per-request hardware signature/nonce scheme yok.
- Profile/plan/document-review complete ≠ runtime implemented. **36 authority acceptance hedefi not-executed**; Files/Photos/Auth detailed contracts da acceptance targets, not pass reports.
- Tarihsel source/archive hash varlığı ≠ bütün raw traces/binaries/screenshots/source/private-state'in repo içinde korunması. Public summaries/outcomes kalıcı; raw rerun availability limitleri evidence docs'ta açık.

## Desktop platforms and isolated signing — current gate

[ADR0015](../decisions/0015-desktop-platform-and-signing-isolation.md): desktop targets Mac/Windows/Linux independently. Only free Apple Personal Team is available; paid membership-dependent Mac signing/provisioning remains **open**, without ad-hoc entitlement, legacy Keychain or software-key bypass. The actual Mac Secure Enclave creation failure is missing entitlement `-34018`.

Development `com.kloda.desktop.dev` and production `com.kloda.desktop` have separate built-package/local authority identities. Authorized host-main entitlements, actual provisioning and Keychain access groups remain distinct; use the profile-authorized App ID prefix, which must not be assumed identical to Team ID. Default production transition is fresh identity and QR re-pairing, not key/pin/epoch/DB copying.

Ayhan reports Windows11 x64 MSVC test-source compilation, desktop-node cargo check and53 native runtime tests PASS (0 failures/ignored,0.63s; doc-tests0/PASS). Real loopback TLS uses test-only software fixtures; production TPM/pairing runtime was not executed. Reported naming/unused_unsafe warnings are nonblocking, with no suppression. Approved windows-sys0.61.2 backs TPM-only CNG signing, physical direct-LAN routes/socket constraints and protected KnownFolder LocalAppData/NTFS authority storage. Native suite PASS does not prove hardware custody/non-exportability/device-key TLS, real protected storage durability or physical LAN; these remain open. No software fallback/continuity reset. Linux has no physical device and native custody/LAN/private-storage remains unsupported. Independent source CI is configured, not observed running; manual Windows results are not CI PASS. See the [validation plan](../implementation/desktop-platform-validation-plan.md).
