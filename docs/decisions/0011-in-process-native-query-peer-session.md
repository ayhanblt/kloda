# ADR 0011 — In-process native query peer-session yönü

> **Current V1 LAN override — 2026-10-13:** [ADR0016](0016-v1-pc-local-file-authority.md) replaces the account/central signed capability/time/issuer/KMS requirements below for LAN with native PC-local SQLite ACL and separate explicit backup-scope approval. Native owned session/TLS/pins/possession/installation continuity/current operation/revoke/publication fence remain; Electron manages only and cannot mint authority. Valid native certificate/profile is still required, not central exact-DER online reissue. FINAL remote authorization and recovery/central revocation versus offline PC/local grants are OPEN. No ACL/query receiver/unpair implementation is claimed.

- Tarih: 2026-10-05; identity cutover kayıt tarihi: 2026-10-07
- Durum: owned in-process query/session yönü korunur; Matrix SDK-owned auth signer prerequisite [ADR0012](0012-kloda-owned-p256-device-identity.md) ile retired
- Tarihsel ilk onay: “In-process custom-signer yönü”; sonraki identity onayı bağımsız Kloda P-256 + o evrede Matrix yalnız ilk SAS idi

2026-10-07 scoped supersession: [ADR0013](0013-qr-based-local-lan-pairing.md) ilk SAS/SDK/store ve SAS↔Kloda binding gerekliliklerini backend-independent yerel QR ile değiştirir; owned in-process query/session ve managed/native ownership sınırları korunur.

## Güncel karar

[ADR0010](0010-operation-bound-pc-commit-proof.md)'daki authenticated PC durable result query native owned canlı session üzerinde kalır. Shared native core, Swift/Kotlin ve Electron main sınırları key export veya caller-created authority context üretmez. **Matrix arbitrary-byte signer/API/sync adaptation artık before-code bağımlılığı değildir.**

1. Device auth ayrı uzun ömürlü Kloda ECDSA P-256 key ile, mümkün olduğunda non-exportable platform hardware provider üzerinden tercih edilir. İlk trust yerel QR invitation, actual mutual TLS possession/PC SPKI equality, aynı-channel secret proof, explicit PC approval ve durable local pins'tir; backend/login gerekmez. Matrix SDK/SAS/Olm/store/binding current path'ten çıkarılmıştır; single Matrix/software identity varsayımı geri gelmez.
2. LAN fresh full pinned TLS1.3/SPKI + session-start mutual device proof; actual certificate DER/SPKI ve Kloda local pin/channel association gerekir. Initial QR PC fingerprint actual TLS'te kullanılan Kloda P-256 canonical SPKI SHA256 ile eşittir, capability exact-DER hash'i değildir. Remote WebRTC/DTLS + signed signaling/fingerprint/mutual proof yönü ADR0012'dedir; bu query ADR'si remote wire contract'ı seçmez ve initial QR equality'den remote profile türetilmez. Native identity/session evidence file authority değildir.
3. `rustls` public custom-signer yüzeyi yalnız historical source-backed **candidate**; exact library/release/provider/features/lock adoption yok. P-256 native provider/callback/lifetime/error/signature-encoding ve owned session APIs gerçek selected source ile sabitlenmeden fake factory/ABI yazılmaz. Private export, unsupported private SDK account access, custom TLS handshake veya client-auth-off fallback yok.
4. Eski upstream-first Matrix byte API proposal ve async preparation→sync SDK signer adaptation historical/retired'dır. Historical patch/vendor fork/lost final corpus rebuild kabul edilmedi; supported upstream API otomatik adoption/migration yaratmaz. Contribution policy/search archival/non-actionable olarak korunur; current upstream task/alternatif/TODO veya product blocker değildir.
5. In-process iş app process çalışırken vardır; iOS URLSession system-background daemon veya force-termination sonrası transfer garantisi değildir. Secure Enclave provider/background integration exact native/physical gate; OS opportunity yoksa pending/wait. iOS16.4+/AndroidAPI24 support hedefi daraltılmaz.
6. Account/PC scope approval, signed capability/time/current deny/revoke ve durable publication fence ayrıca gerekir. Backend user JWT peer grant değil; historical result current grant/availability değil. Nest/Supabase media bytes/catalog/hash ledger veya endpoint private key tutmaz; server issuer signer ayrı rol ve ES256 provisional kalır.
